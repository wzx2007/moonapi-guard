# MoonAPI Guard：MoonBit 原生 OpenAPI 兼容性检查工具

**项目类型：** 开发者工具 / 可复用基础库。  
**实现语言：** MoonBit（核心），JavaScript（文件 I/O、CLI、展示）。  
**许可证：** Apache-2.0。  
**参赛者：** 魏泽瑄（北京邮电大学），团队 w1tness。  
**GitHub ID：** wzx2007。  
**公开仓库：** https://github.com/wzx2007/moonapi-guard

## 问题与目标

API 描述发生变化时，普通文本 diff 无法判断旧客户端是否仍可工作。特别是枚举、必填字段和类型变化，在请求与响应中的兼容方向不同。本项目提供 MoonBit 原生契约比较库，并配套可接入 CI 的命令行工具与可复现演示。

## 本期实现内容

第一版读取 OpenAPI 3.0 JSON，比较操作删除、参数和请求体必填变化、类型/枚举/空值/对象字段/数组/边界约束及媒体类型；支持文档内对象引用和参数继承覆盖。每项结果包含规则、操作、逻辑路径及说明。提供 JSON、文本、Markdown、HTML、SARIF、CSV 报告和 CI 退出码。

项目特别区分“发现风险”和“分析不完整”。新增声明式鉴权继承及权限收紧检查；外部引用、复杂组合、凭据定义变化和递归结构超限明确要求复核，避免静默通过。核心引擎不访问网络；浏览器演示使用与 CLI 相同的 MoonBit 编译产物。

## 交付与验证

交付核心库、CLI、中文演示、四类示例、跨后端行为测试、生成式方向测试、CLI 集成测试、架构和支持范围文档。具体完成的验证和工具链版本见 docs/VALIDATION.md 与 TOOLCHAIN.md。发布时使用真实公开仓库和实际 Mooncakes 命名空间。

## 原创性与来源

依据公开 OpenAPI / JSON Pointer 规范自行实现，没有移植 oasdiff 源码或测试。MoonBit 标准库来源与许可证在 THIRD_PARTY_NOTICES.md 中列明。

## 验收演示

运行本地页面，对比示例订单 API，展示七项风险；切换兼容变更得到 compatible；切换鉴权收紧得到 breaking；切换响应头示例得到 incomplete。导出报告，再用命令行验证对应退出码。
